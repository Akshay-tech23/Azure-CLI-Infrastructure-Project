# Azure CLI Infrastructure Project (AZ-104)

> A hands-on Azure Administrator project built while preparing for the Microsoft Certified: Azure Administrator Associate (AZ-104) certification.

## Project Goal

This repository documents a complete Azure infrastructure deployment using Azure CLI, following a structured 10-day learning plan.

The project focuses on practical Azure administration skills rather than exam memorization.
