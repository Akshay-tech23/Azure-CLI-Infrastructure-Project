# Project Overview

## Project Name

**Azure CLI Infrastructure Project**

---

# Introduction

The Azure CLI Infrastructure Project is a hands-on learning project designed to develop practical Azure Administrator skills through real-world infrastructure deployment and management.

Instead of relying primarily on the Azure Portal, this project emphasizes infrastructure administration using the Azure Command-Line Interface (Azure CLI), Linux system administration, and structured documentation.

The project follows a progressive, lab-based approach where each day introduces new Azure services and administration concepts while building upon the existing environment.

---

# Project Objectives

The primary objectives of this project are to:

- Gain hands-on experience with Microsoft Azure.
- Learn Azure administration using Azure CLI.
- Develop Linux server administration skills.
- Understand Azure networking and security.
- Practice infrastructure troubleshooting.
- Build a production-style GitHub portfolio.
- Prepare for the Microsoft AZ-104 certification.
